The first release of vunit-python-bridge, a VUnit package making Python callable from VHDL, for NVC, GHDL, Questa/ModelSim and, untested, Riviera-PRO/Active-HDL.

## Known issues

- **Linux, standalone Python builds** (for example python-build-standalone): tkinter fails in the simulator, so the dialogs and plots of the `embedded_python` example fail with `libtcl9tk9.0.so: cannot open shared object file` or `Cannot find a usable init.tcl`. Fixed by #3, for the next release.
- **Windows**: a matplotlib Tk window crashes the simulator when the simulator has a Tcl of its own with a different version than Python's, for example NVC 1.22 (Tcl 9) with Python 3.13 or older, or Questa with Python 3.14. The cause is in Pillow and matplotlib. Workarounds: a Python with the Tcl version of the simulator, or a matplotlib backend without Tk. See #5.
- The PySimpleGUI tests of the example open dialogs and wait for an answer, so they need a display and someone to answer them.
