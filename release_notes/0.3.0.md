
## Features

- The `std_ulogic_vector`, `signed` and `unsigned` results of `eval` and `call` are also functions taking the width like `to_unsigned`, as a length or as `size_res`: `byte := call_unsigned("model.pop", byte'length)`. (#15)
- Python objects: `python_object_t` is an instance of a Python class owned by VHDL, whose methods VHDL calls. See "Python objects" in the user guide. (#15)
- Riviera-PRO is a supported simulator. (#21)
