## New features

- `python_object_t`: an instance of a Python class owned by VHDL, created on first use in a session of its own and called with `call(object, "method", ...)` and `eval(object, "expr")`. `get(object, class_name, args, id)` gives a verification component a backend of its own unless the testbench gives it one. See "Python objects" in the user guide.

## Changes

- `import_module_from_file` resolves a relative path against the directory of the testbench file, like `exec_file`, rather than against the working directory of the simulator. It must be called after `test_runner_setup`. Callers that relied on a path relative to the working directory must pass an absolute path instead. See #7.
