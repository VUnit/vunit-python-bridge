## Changes

- `import_module_from_file` resolves a relative path against the directory of the testbench file, like `exec_file`, rather than against the working directory of the simulator. It must be called after `test_runner_setup`. Callers that relied on a path relative to the working directory must pass an absolute path instead. See #7.
- The bridge library is no longer built in or copied to the VUnit output path, which may not allow executing files. A prebuilt Windows DLL is loaded from the installed package, and a built library is cached in the cache directory of the user. `VUNIT_PYTHON_BRIDGE_LIBRARY_DIR` selects another directory on every platform.
